Esta es una página de ejemplo de un cliente del tenant, para probar el widget embebido.

El widget se instala pegando este snippet antes de </body>: 

<script src="http://localhost:8000/widget.js"
        data-api-key="ao_pk_TU_CLAVE_DE_WIDGET"
        data-api-url="http://localhost:8000"></script>

Esta página en concreto lee la clave de la URL (?key=ao_pk_...) para no tener que editar el archivo a mano durante la verificación — en un sitio real, el snippet de arriba se pega tal cual, con la clave ya fija en el data-api-key.
